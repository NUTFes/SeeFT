# 年間カレンダーと人手でやった作業

45th（2026年）の技大祭で、SeeFTまわりの作業がいつ、誰の手で行われたかを記録したものである。46thはこの記録を逆算カレンダーにして、人員と日程を見積もる。

「人手でやった作業」は、46thでどこを自動化するか、そもそもやめるかを判断する材料でもある。所要時間が空欄の行は、分かる人が埋めること。45thの担当者の記憶から埋めるのがいちばん正確である。

## 途中参加の人を足す手順

途中から参加した人をシフトに載せるには、4つのファイルにわたる5つの手順が要る。

1. 執行部が、マスター名簿の全体名簿に追加する
2. SeeFTが、マスター名簿の固定名簿の**末尾**に、同じ表記で追加する（希望調査に自動で反映される）
3. 本人が、希望調査に参加できない時間を記入する
4. SeeFTが、シフトスプシのSeeFTメニュー「メンバーを追加」を実行する。追加した列は局のまとまりの外に入るので、所属する局の位置へ手で動かす
5. SeeFTが、「参加不可の警告を更新」をもう一度実行する

その後、名簿とシフトを送り直すと、アプリに表示される。
