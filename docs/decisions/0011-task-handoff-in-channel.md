# 0011: タスクの割り振りは DM ではなくチャンネルでし、対面は相手が望んだときに設ける

- 状態：採用
- 決めた日：2026-07-23
- 決めた人：45th の PM
- 出典：#420〜#424（このやり方で割り振ったテストのタスク）

## 背景

テストを書くタスク（#420〜#424）を、メンバーに1件ずつ割り振ることになった。割り振りの連絡を Slack の DM で送るか、先に対面の日程を決めて説明するか、を決める必要があった。

## 候補

| 候補 | 良い点 | 悪い点 |
| --- | --- | --- |
| DM で送り、先に対面で説明する日程を決める | 手厚く説明できる | やり取りがほかの人から見えない。相手に日程を合わせる負担がかかる |
| チャンネルに投稿し、話したいことが出たときだけ対面や通話を設ける（非同期を先にする） | 記録が残り、ほかのメンバーも読める。相手が自分の時間で読める | 説明が足りないと、相手が詰まる |

## 決定

タスクの割り振りや依頼は、DM ではなくチームのチャンネルに投稿する。投稿には、相手へのメンション、issue のリンク、お手本や設計のリンクを入れ、「質問があれば対面か通話の時間を取ります。なければ次の MT か作業会で」と締める。対面や通話は、相手が望んだときに設ける。

## 理由

割り振りは、記録が残り、ほかのメンバーも読める場所で共有したい。同じ種類のタスクを持つ人が、ほかの人への説明を参考にできる。話す場を作るかは、相手が必要としているかで決めればよく、先に日程を押さえると、相手の負担だけが増える。
