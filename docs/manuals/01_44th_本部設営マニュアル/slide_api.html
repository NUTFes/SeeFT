作業手順

  1. 現状復帰写真を撮り、slackの#999_現状復帰チャンネルに場所名と共に写真を載せる
  2. 本部内物品準備確認表に従って、本部に物品を運ぶ
  3. 103と104の壁を収納し、1つの部屋にする
  4. 103と104に元々置いてある机と椅子で使用しない物品は養生テープに部屋番号を貼ったうえで、102に移動させる
  5. 配置図をもとに物品の配置を行う
