技大祭物販テント設営・撤収マニュアル

第44回技大祭実行委員会
担当者：河村
作成日：令和7年9月1日
1. 該当シフト

準備日の物販テント設営、当日1日目、2日目の物販テント設営、技大祭物販テント片付け、片付け日の物販片付けシフトに該当する者は、この資料を参考に業務にあたること。

2. 会場・時間
設置場所

技大祭物販テント（福2）は福利棟前に設営する。

図1 会場配置図
集合情報
  • 集合・終了時間：シフトに従う
  • 集合・終了場所：技大祭物販テント
図2 技大祭物販テント配置図
設営
3. 準備日の設営（10:00〜18:00）
時間 やること
10:00〜10:30 ・運営本部（電気棟1階103）の窓口で物品貸出表、模擬店平面図、機保護用のゴミ袋、衛生テープを受け取る
・講義棟の貸出物品（机、椅子）をテントの設営場所まで運ぶ
10:30〜12:00 ・体育館でテントと掲示板を設営場所まで運ぶ
12:00〜14:00 昼休憩、別作業
14:00〜14:30 テントを立てる
14:30〜15:30 ・図2の配置図を参考に物品を配置する
15:30〜16:00 テントの足を倒し、物品を中に収める
16:00〜18:00 アイスボックスが届き次第、テント内に収める
（テント布に物品が当たっていないか等を総務局に確認してもらいながら作業する）
運営
4. 1日目・開店作業（8:00〜10:00）
時間 やること
8:00〜9:00 ・運営本部（電気棟1階103）に封筒、衛生テープを取りに行く（2人）
・テントを立て、図1を参考に物品の配置を行う（開店チェックリストに従う）
・体育館前に河村と志賀の車を停め、積載している飲料を運び出す
・準備完了したら開店チェックを受ける
・体育館前の水道でアイスボックスの半分程度まで入れる
9:00〜9:45 1日目のみ開会式に出席する（河村がテントに待機）
9:45〜10:00 ・12kgの氷をアイスボックスに投下し、飲料を入れて冷やしておく
10:00〜 営業開始
5. 1日目・屋外販売の閉店作業（16:45〜17:30）
時間 やること
16:30〜17:00 ・物品を体育館に搬入（テントは立てたまま）
・体育館に持っていかない飲料の段ボールを河村の車に積み込む
・加藤と長谷野はラ・ムーへ氷を買いに行く（17:00に到着するとラ・ムーに連絡済）
6. MUSIC NUTs対応物販延長販売・開店作業（16:30〜17:30）
時間 やること
16:30〜17:00 ・物品を体育館に搬入（テントは立てたまま）
・体育館に持っていかない飲料の段ボールを河村の車に積み込む
・加藤と長谷野はラ・ムーへ氷を買いに行く（17:00に到着するとラ・ムーに連絡済）
17:00〜17:30 ・販売スペースのセッティングを行う
・アイスボックスに水と氷を入れ、飲み物を冷やしておく
17:30〜 延長販売開始

7. 2日目の閉店作業
延長販売の閉店準備（20:00〜20:30）
時間 やること
20:00 延長販売終了
20:00〜20:30 ・体育館内の物品をテント内に収める
・総務局の開店チェックを受け、テントを畳む
・売上金を計上し、お金をすべて財務局長（北さん）に渡す。余った飲料や段ボールを24に持っていく
2日目閉店作業
時間 やること
16:00 営業終了
16:00〜17:00 ・閉店チェックリストに従い作業を行う
・作業完了次第、閉店チェックを受ける
・売上を計上し、お金をすべて財務局長（北さん）に渡す
・万彩の宴用に机2脚を体育館まで運ぶ
片付け
8. 片付け日の撤収
時間 やること
10:00までに 貸出物品表、雑巾を本部で受け取る（河村）
10:00〜12:00 ・テントを解体する
・机、椅子を雑巾で拭く
・借用物品を物品貸出表に記載された場所へ返却する
・アイスボックスを北さんの部屋まで持っていく
12:00〜14:00 業者がアイスボックスを回収
