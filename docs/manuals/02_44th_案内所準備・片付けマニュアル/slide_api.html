設営手順
本部の物品窓口にて物品貸出表と物品を受け取る。
物品貸出表に従い、物品をカゴに入れて、台車で設営場所に運ぶ。
※ 配布物は本部で部数を管理しています。持ち出すときは必ず本部待機者に持っていく部数を報告すること。
テントの足を伸ばして、テントを設営する。
機にはゴミ袋、掲示板には透ポリを巻き、養生テープで固定する。
ゴミ袋は機の天板を覆うように巻く。
透ポリは掲示板を横に一周するように巻く。
配置図をもとに机、イス、掲示板の配置を行う。
貸出物品表の使用用途をもとに配布物の配置、掲示物の掲示を行う。
配布物（数十部ずつ）→来場者対応用の机に並べる。
配布物（残り）→持ってきた箱の中に保管。
掲示板用→掲示板に養生テープで掲示。
機掲示用→来場者対応用の机に掲示。
物品貸出表とカゴを本部の物品窓口に返却する。
