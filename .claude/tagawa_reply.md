**「基本情報の後にすぐタスクが来るべき」**
→ めちゃくちゃ良い指摘。現場で見る人は「自分が何をすればいいか」が最優先なので、情報の順番を見直します。

基本情報 → タスク・手順 → スケジュール → 役割分担 → 必要物品

この順番をデフォルトにします。のぼり・幼稚園WARSがいいと感じたのはまさにこの構成になってたから。

**お化け屋敷の量問題 / 役割ごとに分ける**
→ シフトカード側の仕組みで対応できる。お化け屋敷のシフトが「受付」「誘導」「脅かせ役」で分かれていれば、それぞれのシフトカードに該当部分だけのスライドを紐づけることが可能。マニュアル自体を分割するか、1つのHTMLの中で該当セクションに直接飛ばすか、どちらでもいける。

**文字サイズ大きく / 項目に外枠**
→ CSS調整で対応します。

**日にちごとに分ける**
→ 準備日・1日目・2日目・片付け日でセクション分けを明確にする。目次と組み合わせれば「今日の分」にすぐ飛べるようにできる。

**目次からスライドに飛べる**
→ HTMLのページ内リンクで実装します。先頭に目次を置いて、タップしたらそのセクションにスクロールする形。

**スライドの見やすさがマニュアル自体のクオリティに左右される**
→ まさにそうで、今ドキュメントのテンプレートを作ろうとしてるところ。テンプレートが統一されればスライドの品質も安定する。
